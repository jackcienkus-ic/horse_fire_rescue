🗺 The Big Picture

Before writing any code, let's understand what all the pieces are and how they fit together.

What is PostgreSQL?

PostgreSQL (often called "Postgres") is a relational database — it stores data in tables with rows and columns, like a spreadsheet, but much more powerful. You talk to it using SQL (Structured Query Language).

How does Kotlin talk to it?

Kotlin (running on the JVM) uses a standard called JDBC (Java Database Connectivity) to communicate with databases. You need two things:

🔌 JDBC Driver

A library (JAR file) that knows how to speak PostgreSQL's network protocol. Think of it as a translator.

🔗 Connection String

A URL that tells the driver where your database lives, what it's named, and your credentials.

The flow

Your Kotlin code

Key vocabulary

  • 🗃
    Table — where data is stored (like a spreadsheet tab)
  • 📋
    Row — one record (e.g., one user)
  • 📊
    Column — one field on a record (e.g., "email")
  • 🔑
    Primary Key — a unique ID for each row
  • 📝
    SQL Query — a command you send to the database (SELECT, INSERT, UPDATE, DELETE)
  • 📦
    ResultSet — what Kotlin gets back after a SELECT query (like a cursor over rows)
💡 PostgreSQL runs as a separate program (a server) on your machine or in the cloud. Your Kotlin app connects to it over a network, even if they're on the same computer.

⚙️ Project Setup

You need PostgreSQL installed, and your Kotlin project needs the JDBC driver as a dependency.

1. Install PostgreSQL

  • 🍎
    Mac: brew install postgresql@16 then brew services start postgresql@16
  • 🪟
    Windows: Download the installer from postgresql.org/download
  • 🐧
    Linux: sudo apt install postgresql

2. Create a database

Open your terminal and run:

# Log into PostgreSQL
psql -U postgres

# Inside psql, create a database
CREATE DATABASE myapp;
\q   -- quitpsql

3. Add the driver to your Kotlin project

In your build.gradle.kts file, add the PostgreSQL JDBC driver:

dependencies {
    implementation("org.postgresql:postgresql:42.7.3")
}build.gradle.kts
⚠️ Make sure to sync/reload your Gradle project after adding the dependency so the driver downloads.

4. Verify your connection details

Default PostgreSQL connection info (local dev)
  • host localhost
  • port 5432
  • database myapp
  • user postgres (or your system username)
  • password whatever you set during install

🔗 Connecting from Kotlin

Here's how to open a connection to your PostgreSQL database.

The connection URL format

jdbc:postgresql://HOST:PORT/DATABASE

Basic connection code

import java.sql.DriverManager

fun main() {
    val url  = "jdbc:postgresql://localhost:5432/myapp"
    val user = "postgres"
    val pass = "yourpassword"

    // "use" automatically closes the connection when done
    DriverManager.getConnection(url, user, pass).use { conn ->
        println("Connected! Is closed: ${conn.isClosed}")
    }
}Kotlin
💡 .use { } is Kotlin's way of ensuring a resource (like a database connection) is always closed when you're done, even if an error occurs. Always use it!

Create a table to work with

Let's create a simple users table to run queries against. You can do this in psql or add it to your Kotlin code:

-- Run this in psql or as a query in Kotlin
CREATE TABLE users (
    id    SERIAL PRIMARY KEY,     -- auto-incrementing ID
    name  TEXT NOT NULL,
    email TEXT UNIQUE NOT NULL
);SQL

What is SERIAL?

SERIAL tells PostgreSQL to automatically generate a unique integer ID for each row. You never have to set it yourself.

📝 Running SQL Queries

There are two main tools: Statement for static SQL, and PreparedStatement for SQL with variables. Always use PreparedStatement when inserting user data.

INSERT — add a row

val sql = """
    INSERT INTO users (name, email)
    VALUES (?, ?)
"""

conn.prepareStatement(sql).use { stmt ->
    stmt.setString(1, "Alice")   // first ?
    stmt.setString(2, "alice@example.com")  // second ?
    stmt.executeUpdate()           // run it
}Kotlin

SELECT — read rows

val sql = "SELECT id, name, email FROM users"

conn.createStatement().use { stmt ->
    stmt.executeQuery(sql).use { rs ->
        while (rs.next()) {         // move to next row
            val id    = rs.getInt("id")
            val name  = rs.getString("name")
            val email = rs.getString("email")
            println("$id: $name ($email)")
        }
    }
}Kotlin

SELECT with a WHERE clause

val sql = "SELECT * FROM users WHERE email = ?"

conn.prepareStatement(sql).use { stmt ->
    stmt.setString(1, "alice@example.com")
    stmt.executeQuery().use { rs ->
        if (rs.next()) {
            println("Found: ${rs.getString("name")}")
        }
    }
}Kotlin

UPDATE and DELETE

// UPDATE
conn.prepareStatement("UPDATE users SET name = ? WHERE id = ?").use { stmt ->
    stmt.setString(1, "Alicia")
    stmt.setInt(2, 1)
    val rowsAffected = stmt.executeUpdate()
    println("Updated $rowsAffected row(s)")
}

// DELETE
conn.prepareStatement("DELETE FROM users WHERE id = ?").use { stmt ->
    stmt.setInt(1, 1)
    stmt.executeUpdate()
}Kotlin
⚠️ Never build SQL strings with string interpolation like "SELECT * FROM users WHERE id = $id". This opens you up to SQL injection attacks. Always use ? placeholders.

✅ Best Practices & Next Steps

A few habits that will save you headaches as you build real projects.

Dos and Don'ts

  • ✅
    Always use .use { } to close connections, statements, and result sets automatically.
  • ✅
    Always use PreparedStatement when your query includes any variable data.
  • ✅
    Use a connection pool (like HikariCP) in real apps so you're not opening/closing a new connection for every query.
  • ✅
    Store credentials in environment variables, not hardcoded in source code.
  • ❌
    Don't build SQL with string templates — use ? placeholders instead.
  • ❌
    Don't leave connections open — always close them in a finally block or with .use { }.

Using a connection pool (recommended for real projects)

// build.gradle.kts
implementation("com.zaxxer:HikariCP:5.1.0")

// Kotlin setup
val config = HikariConfig().apply {
    jdbcUrl  = "jdbc:postgresql://localhost:5432/myapp"
    username = System.getenv("DB_USER")
    password = System.getenv("DB_PASS")
    maximumPoolSize = 10
}
val dataSource = HikariDataSource(config)

// Use it the same way
dataSource.connection.use { conn ->
    // your queries here
}Kotlin
